# Page CV (/cv, A4 imprimable) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Créer `/cv` : un CV A4 statique, style du site (Bricolage + Manrope, monochrome), 2 colonnes à ordre DOM linéaire, bilingue, exportable en PDF vectoriel via l'impression du navigateur — et activer le bouton « Voir le CV » de À propos.

**Architecture:** Le contenu bilingue vit dans `Cv.content.ts` (données + `getCvContent(lang)` qui résout tout dans la langue). `Cv.tsx` rend une « feuille A4 » blanche (couleurs claires fixes) dans un cadre thémé, avec un bouton `window.print()` ; `Cv.css` porte les dimensions A4 + le bloc `@media print` qui masque le chrome du site. Le câblage (route, SEO, App, lien À propos) est isolé dans une 3ᵉ tâche.

**Tech Stack:** React 19 + Vite + TS ; Tailwind v4 (CSS) ; react-router v7 ; Vitest + @testing-library/react ; Biome ; polices `--font-manifeste` (Bricolage) + Manrope déjà présentes.

**Spec:** docs/superpowers/specs/2026-08-21-cv-page-design.md

## Global Constraints

- **Monochrome** : le cadre de page utilise les tokens `--portfolio-*` (theme-aware) ; la **feuille** utilise des couleurs **claires fixes** (`#fff` fond, `#1A1A1A` texte, `#E0E0E0` filets) pour rester blanche en thème sombre ET à l'impression. Aucun accent couleur.
- **Statique** : aucune animation/motion sur `/cv`.
- **Bilingue** FR + EN, parité stricte (mêmes longueurs de listes), suit `useLang()`.
- **Ordre DOM = ordre de lecture linéaire** (en-tête → accroche → Expérience → Compétences → Outils → Formation → Langues) même si le rendu est en 2 colonnes (via CSS grid, sans casser l'ordre source) → PDF texte parseable (ATS).
- **Texte réel** partout : pas de barres de compétences, pas d'info portée par une icône, pas de texte en image.
- **Pas de lien mort** : LinkedIn n'a pas encore d'URL → tant que `LINKEDIN_URL` est vide, afficher « LinkedIn » en texte simple (pas de `<a href>`).
- **Photo** : emplacement réservé avec placeholder neutre (pas d'`<img>` tant que l'asset n'est pas fourni).
- **Pas de nouvelle dépendance.** Budget ≤ 190 kB gzip (page lazy, chunk séparé).
- Import motion depuis `motion/react` si jamais utilisé (mais la page n'anime rien).
- Chaque tâche finit par `npx vitest run <fichier de test>` vert, puis un commit.
